# Análisis y Consolidación de Datos de Telecomunicaciones (Interconnect)

## 🎯 Objetivo y Metodología
- **Problema:** Integración de múltiples fuentes de datos relacionales (contratos, demografía y servicios) para evaluar el comportamiento de los usuarios y estudiar la cancelación del servicio (churn).
- **Metodología:** Gestión de valores nulos, estructuración de datos (Data Wrangling) y construcción de la variable objetivo mediante scripts de Python y SQL.

## 📊 Resultados y Métricas
- **Entregable:** Dataset unificado y estructurado para evaluar los factores de abandono de los usuarios.
- **Métrica clave:** Desarrollo de un modelo de alto rendimiento alcanzando un **AUC-ROC de 0.9042** con LightGBM para anticipar la deserción de clientes.

## 🛠️ Tecnologías y Librerías
- **Lenguaje:** Python, SQL
- **Librerías y técnicas:** Pandas, Data Wrangling, Scikit-Learn, LightGBM
